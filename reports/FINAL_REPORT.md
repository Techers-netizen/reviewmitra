## 4. T3 Headed Login Handoff Workflow

To capture authenticated sessions without exposing passwords or violating Safety Rule 3, the interactive headed login script has been prepared at [`scripts/login-handoff.js`](file:///c:/Users/lenopvo/Desktop/Reviewmitra/scripts/login-handoff.js).

### How It Works:
1. When launched, a real headed Chromium browser pops up on your Windows desktop.
2. An interactive floating header appears: `[ReviewMitra Login Handoff] Please log in. When done, click [Save Session & Continue]`.
3. You manually enter your credentials, complete SMS OTP or 2FA, and click the green button.
4. Playwright exports your authenticated browser state to `qa/sessions/<platform>-state.json` (strictly gitignored in `.gitignore`).
5. After session capture, `scripts/real-platform-dry-run.js` re-opens the real platform, opens the vendor reply box, types the AI response, and saves a high-res screenshot without submitting.

### Commands to Run Handoff (One by One):
```powershell
# 1. Google Business / Maps Handoff
node scripts/login-handoff.js google

# 2. Facebook Page Admin Handoff
node scripts/login-handoff.js facebook

# 3. Justdial Vendor Portal Handoff
node scripts/login-handoff.js justdial

# 4. IndiaMART Seller Panel Handoff
node scripts/login-handoff.js indiamart
```
